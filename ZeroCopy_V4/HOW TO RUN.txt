###### FILES #########
- MakeFile เป็นแค่ตัวสร้างไฟล์จำลอง ไม่ได้ใช้ในการทำงาน
- Server
- Client

# 1. Compile
javac -encoding UTF-8 Server.java Client.java MakeFile.java

# 2. สร้างไฟล์ทดสอบ (100 MB)
java MakeFile files\<file_name>.bin <files size (หน่วยเป็น MB)> และจะถูกเก็บใน folder "files"

ตัวอย่างการสร้าง :
java MakeFile files\bigfile.bin 100

# 3. รัน Server (Terminal 1)
java Server 9000

# 4. คำสั่ง Client (Terminal 2)

# Optional
java Client 9000 LIST
java Client 9000 INFO bigfile.bin
java Client 9000 HASH bigfile.bin
java Client 9000 GET bigfile.bin 0 1000 traditional
java Client 9000 GET bigfile.bin 0 1000 nio
java Client 9000 INFO nofile.bin                      # ทดสอบ ERROR 404

# Run test
รูปแบบคำสั่งคือ `java Client <port> <file> <traditional|nio> <1|3>` โดยตัวเลขท้ายคือจำนวนรอบ ใส่ได้เฉพาะ 1 หรือ 3
(จากเอกสาร "อย่างน้อยทดสอบ 1 worker และ 10 workers สำหรับแต่ละวิธี และรันแต่ละกรณีอย่างน้อย 3 ครั้ง")

java Client 9000 GET bigfile.bin 999999999 10        # ทดสอบ ERROR 416
java Client 9000 bigfile.bin traditional 3           # รันทดสอบความเร็ว traditional
java Client 9000 bigfile.bin nio 3                   # รันทดสอบความเร็ว nio

# มี folder "dowloads" สำหรับเก็บไฟล์จากการ run , "logs" สำหรับเก็บบันทึก

++++++++ ปล. เนื่องจาก LIST, INFO, GET มีการทำงานอยู่แล้วตามลำดับใน code แต่จากรูปแบบเอกสารทำให้ไม่มั่นใจว่าต้องเขียนแยกเพื่อ run ใน Terminal ไหม ?
         จึงได้ทำในส่วน Optional ขึ้นมาเพื่อป้องกันไว้ก่อน ++++++++++
